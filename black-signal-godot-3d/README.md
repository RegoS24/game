# BLACK SIGNAL 3D | v0.6
Native Godot 4.5.1 3D, OpenGL compatibility renderer. New Android package com.blacksignal.nox3d; old WebView game remains in its branch. This is a first playable 3D vertical slice, not finished AAA production art.

Open project.godot in Godot 4.5.1. WASD, right mouse drag camera, left mouse or F fire, E interact, R reload, Q heal, C crouch, space jump, I inventory, 1–3 switch. Android landscape touch joystick, camera drag, separate fire buttons and HUD. Four original procedural mesh characters; real 3D buildings, traffic props, emissive facade shader, wet road shader, lighting, six enemies, a short quest, inventory and weapon presets. Lobby and loading UI implemented in engine. Current art uses simplified procedural geometry, not the previous cinematic image or a finished AAA rig. No online multiplayer. No port of the full previous 2D campaign or saves yet.

CI imports / executes headless smoke test / exports native APK. Physical Android device verification still needed.
