# BLACK SIGNAL • RIN
Офлайн 2D Action RPG в Нокс-Сити. Шесть районов, пять глав, три концовки, задания, противники, торговцы, прокачка и сохранение. Рин — спрайты из предоставленного концепта, 30 кадров: idle / walk / run / jump / dash. Переходы смешиваются по времени, для стрельбы и урона используются процедурные эффекты. Боковые кадры зеркалируются; полноценные отдельные ракурсы движения вперёд/назад и боевые спрайты ещё не нарисованы.

## Запуск
Открыть `app/src/main/assets/index.html` в браузере. WASD — движение, Shift — бег, X — прыжок, Space — рывок, E — диалог, ЛКМ/F — огонь, R — перезарядка, Q — лечение. На телефоне — экранный джойстик и кнопки. Горизонтальная ориентация.

## Android
GitHub Actions запускает `build-apk.sh` и размещает APK в Artifacts и Releases. В локальном архиве workflow рассчитан на папку `black-signal-rin` в репозитории; для самостоятельного репозитория уберите этот префикс путей и working-directory. APK подписывается временным debug-ключом; обновление такой сборки может потребовать переустановки и потерю локальных сохранений. Это не Play Store release. Для локальной сборки нужен Android SDK platform 34, build-tools 34.0.0, JDK 17 и zip.

## v0.3 — Арсенал
Пять видов оружия, разные магазины, темп, дальность, урон и отдача. Дробовик стреляет шестью дробинами, плазма усиливает урон против механических противников. Два слоя анимации рук: прицеливание, отдача, перезарядка. Оружие покупается в Киоске 24. Клавиши 1–5, Tab для смены, ПКМ для прицеливания, R для перезарядки. Android: кнопки смены оружия и перезарядки в HUD. APK подписан отладочным ключом CI; при несовместимой подписи старой версии потребуется переустановка.


## v0.4 — Инвентарь
Трёхколоночный интерфейс в духе PUBG: лут рядом, персонаж и экипировка, два длинноствольных оружия, пистолет, модули и рюкзак. Перетаскивание на ПК, кнопки на мобильных. I / B — инвентарь, 1–3 — слоты, Tab — смена. Боеприпасы конечны, их можно найти у противников и купить в магазине. Шлем и жилет снижают урон, рюкзак повышает вместимость. Коллиматор, компенсатор и быстрый магазин меняют характеристики. Старые сохранения мигрируют при запуске, если данные приложения сохранены. CI использует разные отладочные ключи; установка обновления поверх старой APK может быть невозможной.
