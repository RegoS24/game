# BLACK SIGNAL — native HD2D v0.6.2
Godot 4.5.1, no 3D nodes/models, Android landscape, independent project. 216 interpolated raster frames: idle 32, walk and run 40 each, jump 36, crouch 32, prone 36. Reversible stance transitions, time-driven loop, speed-dependent cadence, hysteresis and phase-preserving transitions. Uses the same eight source keyposes for each animation; visual imperfections are still possible. City is a procedural 2D training street, not AAA art. The five targets, ammunition system, fullscreen lobby, loading and touch controls are functional code; story and original inventory aren't migrated. No independent side or crawling pose cycles. Build pipeline generates dense sheets before importing and exporting, tests the headless animation state machine and then installs/taps the native APK on an Android emulator before publishing. Physical-phone testing is still necessary.
Local source: python -m pip install pillow numpy opencv-python-headless; python prepare_atlases.py; godot --headless --editor --import --quit; godot --path .
