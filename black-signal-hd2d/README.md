# BLACK SIGNAL — native HD2D v0.6.3
Android landscape, Godot 4.5.1, rear third-person view, strictly 2D raster Rin. 292 frames on 384x512 cells: idle 48, walk 60, run 48, jump 48, crouch 40, prone 48. The eight original key poses per clip still limit true animation and detail. Real-ESRGAN anime video v3 restores the key art (in build only), clean alpha and two-way inverse optical flow produce intermediates. This is not a newly hand-drawn HD source. Loop boundary, speed hysteresis, joystick dead zone, jump lift, shadow and rendering workload adjusted. 60 FPS target, not a measured phone frame rate. Original environment, combat, training goals and lobby remain. The existing headless smoke and Android emulator checks must pass before release. Physical-device animation, appearance and performance need playtesting.

Local generation: install pillow numpy opencv-python-headless and CPU torch 2.6.0; obtain official realesr-animevideov3.pth from xinntao/Real-ESRGAN v0.2.5.0 and set RIN_SR_WEIGHTS to its path. Run python prepare_atlases.py then godot --headless --editor --import --quit. Neural restoration uses the BSD-3-Clause Real-ESRGAN project architecture and published checkpoint for preprocessing only.
