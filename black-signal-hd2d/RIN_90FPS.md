# v0.7.5 — 90 Hz Rin animation
All eight player clips sampled at 90 frames/second at nominal playback speed. Counts: idle 162, walk 90, run 72, jump 72, crouch 45, prone 61, crouch-walk 104, crawl 136, total 742. One-shot sequences include both endpoints, so intervals=count-1. Loop duration quantized to whole frames; the original step rhythm, leg alternation tests, locomotion speed adaptation, and stance transitions are retained. Rendering cap is 90 FPS, delta-driven, with existing synchronization. Transparent margins trimmed without pixel resampling; pages <=4096px. Lower movement speed reduces the gait phase rate, not the simulation rate. Physical device refresh rate and GPU/CPU performance determine actual displayed FPS. The source is optical-flow interpolated raster artwork rather than 742 independent drawings. Enemy animation atlases are unchanged. Build verifies cadence and export; no claim of measured 90 FPS on hardware.
